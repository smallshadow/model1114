# 模型含二工｜3D 網頁瀏覽 v2

- 樓層可複選。例：按清空樓層，再點 1 樓、2 樓、3 樓。
- 按只看柱樑，再點牆體，可一起查看柱樑和牆體。柱樑、牆體、樓板、其他可獨立開關；分類依 SketchUp 標籤和群組名稱。
- 全模型半透明會套用到目前顯示的構件。重設視角可重新置中顯示中的模型。
- 跨樓層的面沿樓層界線切開，切面不加封口；模型保留原有材質及貼圖。

將此資料夾內全部內容上傳至 GitHub 儲存庫根目錄，與 index.html 放同一層。已設定 GitHub Pages 的話，只需提交新版，等候重新部署。新版程式與模型有獨立檔名；GitHub 上舊檔可移除。原始 SKP 不需上傳。

本機可用 python -m http.server 8000 從此資料夾啟動，再用瀏覽器開啟 http://localhost:8000/。
